# پرتفولیو و شش نمونه‌کار مستقل · نسخهٔ ۱۰

این بسته سایت اصلی فارسی و راست‌چین، سورس قابل ویرایش و نسخهٔ آمادهٔ اجرا را دارد. سایت اصلی بر اساس ترکیب و موشن قالب Moonex بازسازی شده است. شش نمونه‌کار مستقل دارد: **آتلیه نو، RIFT، VELO، نِوا، وِلیا و راوا**.

## اجرای سریع

۱. ZIP را کامل استخراج کنید.
۲. با نصب Node.js، در پوشهٔ پروژه اجرا کنید:

```sh
node serve.mjs
```

۳. مرورگر را روی `http://localhost:8080` باز کنید. تا زمان بررسی، ترمینال باز بماند.

در ویندوز می‌توانید `start-preview.bat` را اجرا کنید. در macOS/Linux از `sh start-preview.sh` استفاده کنید. نسخهٔ آماده در `dist` است و برای این اجرای سریع نیازی به نصب وابستگی‌ها ندارید. اجرای مستقیم HTML از مسیر `file://` مسیرهای سایت و اسکریپت‌ها را درست اجرا نمی‌کند.

اگر پورت ۸۰۸۰ اشغال است:

```sh
PORT=8081 node serve.mjs
```

در PowerShell: `$env:PORT=8081; node serve.mjs`.

## ویرایش سورس

```sh
npm ci
npm run dev
```

ساخت خروجی و بررسی TypeScript:

```sh
npm run check
npm run build
```

صفحات اصلی در `src/pages`، هویت‌های مستقل در `src/styles/v10`، دادهٔ نمونه‌ها در `src/data/brands.ts` و هندسهٔ سه‌بعدی در `src/three/study-models.ts` هستند. تصاویر محلی در `public/art/v10` قرار دارند.

اطلاعات شخصی و راه‌های ارتباطی را در `src/config.ts` وارد کنید. فرم سایت اصلی تا تنظیم endpoint، درخواست واقعی ارسال نمی‌کند. این نسخه منتشر نشده است.

## چیزهایی که می‌توانید بررسی کنید

- در نمونه‌های آتلیه، RIFT، VELO، نِوا و وِلیا حالت روشن/تیره و کاهش حرکت را از هدر تغییر دهید. راوا پالت مستقل خود را دارد و کاهش حرکت سیستم را رعایت می‌کند. ترجیح سیستم برای کاهش حرکت اولویت دارد.
- آتلیه: آرشیو را فیلتر کنید، عکس‌ها را با کلید جهت یا دکمه عوض کنید، سقف ماکت را بردارید و درخواست همکاری را بازبینی کنید.
- RIFT: رنگ و اندازهٔ موجود در سناریو را انتخاب کنید. اندازه‌های غیرفعال ناموجودند. سبد را تغییر دهید، اطلاعات آزمایشی را بازبینی و اصلاح کنید و رسید نمایشی ببینید.
- VELO: مدل و رنگ را تغییر دهید، بخش‌های باتری، انتقال حرکت و فرمان را از نزدیک ببینید. حرکت افقی موس/لمس یا کلیدهای جهت مدل را می‌چرخاند؛ حرکت عمودی صفحه آزاد است. تصاویر ثابت از همین هندسه گرفته شده‌اند.
- نِوا: نزدیک‌ترین زمان را انتخاب کنید، مراحل رزرو را کامل کنید، زمان را جابه‌جا کنید یا پس از تأیید لغو کنید. زمان‌ها بر اساس ساعت تهران و تقویم شمسی نمایش داده می‌شوند.
- وِلیا: محصول را جست‌وجو و ذخیره کنید، موجودی، نوع پوست و قیمت را فیلتر کنید، تصاویر محصول را بزرگ کنید و سبد را تغییر دهید. کد VELIA10 ده درصد تخفیف نمایشی دارد. یک روتین را یکجا به سبد اضافه کنید، ارسال استاندارد یا سریع را انتخاب کنید و سفارش آزمایشی را در حساب نمونه یا صفحهٔ پیگیری ببینید. حالت روشن پیش‌فرض است؛ حالت تاریک از هدر انتخاب می‌شود. کاهش حرکت سیستم برای موشن‌ها رعایت می‌شود.

- راوا: رنگ و سایز موجود را انتخاب کنید، نماهای موجود هر رنگ را عوض کنید و انتخاب‌ها را ذخیره کنید. کد RAVA10 ده درصد تخفیف پس از تخفیف محصول اعمال می‌کند. پنل و صفحهٔ سبد، حذف قابل برگرداندن، ارسال استاندارد/سریع، بازبینی و رسید نمونه دارند.

## دامنهٔ این نمونه

هر شش پروژه برندها و محتواهای مفهومی دارند. وِلیا ترکیب سه مرجع تصویری کاربر را حفظ می‌کند؛ نام برند، نام محصولات و تصاویر، اختصاصی این نمونه‌اند. پرداخت، ارسال سفارش، احراز هویت، درخواست همکاری و نوبت واقعی وجود ندارند. مشخصات دوچرخه و نقشه‌ها مطالعات بصری‌اند، نه مدارک مهندسی.

سبد پوشاک، پیکربندی دوچرخه و وضعیت نوبت نمایشی روی همان مرورگر ذخیره می‌شوند. وِلیا فقط شناسه و تعداد محصولات، علاقه‌مندی‌ها، تم و رسیدهای فاقد اطلاعات گیرنده را نگه می‌دارد. ورود به حساب نمونه یک پرچم موقت در sessionStorage است. **نام، شماره، ایمیل، نشانی و پیام‌های فرم‌ها ذخیره یا ارسال نمی‌شوند.** نشانی و دیدگاه فقط تا بارگذاری دوبارهٔ همان صفحه پیش‌نمایش می‌شوند. حذف داده‌های سایت در مرورگر این انتخاب‌ها را پاک می‌کند. فرم‌ها در نبود جاوااسکریپت امکان ارسال اطلاعات به روش GET ندارند. در نبود WebGL تصویر ثابت نشان داده می‌شود؛ انتخاب مدل و رنگ VELO همچنان تصویر مرتبط را تغییر می‌دهد.

عکس‌ها و پرتره‌های دموها تولیدشده‌اند. وِلیا هشت تصویر اختصاصی دارد؛ ۲۰ محصول مفهومی از شش خانوادهٔ بسته‌بندی استفاده می‌کنند. پرتره، قاب و پنج تصویر دفتر تصویریِ سایت اصلی از مرجع Moonex هستند و منابعشان در `public/portfolio/moonex/sources.json` ثبت شده است. تصاویر VELO رندر هندسهٔ سایت‌اند. توضیح و منشأ دارایی‌ها در `ASSETS.md` و `assets-provenance-v10.json` آمده است.

## بررسی‌ها

طراحی وِلیا در `design-system/velia.md` و منابع تصاویر در `public/art/velia/sources.json` ثبت شده‌اند. گزارش‌های آزمون `verification-velia.json`، `verification-velia-motion.json` و `verification-velia-flow.json` و شرح محدوده در `QA_VELIA.fa.md` قرار دارند. برای آزمون کاربردی از `npm run test:velia` و برای آزمون حرکت و فوکوس از `npm run test:velia:motion` استفاده کنید. `npm run test:velia:flow` پیوستگی اندازه و موقعیت فیلتر و سبد، انتقال صفحات و جهت بازگشت را اندازه می‌گیرد و در `output/playwright/velia-flow/` ضبط می‌کند. `npm run capture:velia` پیش‌نمایش‌های واقعی پرتفولیو را بازسازی می‌کند؛ پس از ثبت تصاویر دوباره خروجی را بسازید. `npm run capture:velia:motion` مسیرهای حرکتی را در دسکتاپ و موبایل به‌صورت WebM در `output/playwright/velia-motion/after/` ضبط می‌کند. مسیرهای قدیمی `/demo/sukin/` و `/work/sukin/` به صفحه‌های جدید هدایت می‌شوند.

`QA_REPORT.fa.md` نتیجه و محدودهٔ بررسی را توضیح می‌دهد. `verification-v10.json` و `verification-moonex.json` گزارش‌های اجرایی هستند. تصاویر نسخهٔ اصلی در `captures/moonex-fidelity` و تصاویر دموها در `captures/v10` قرار دارند. مشخصات تطبیق با مرجع در `design-system/moonex-template.md` ثبت شده است.

برای اجرای آزمون‌ها پس از نصب وابستگی‌ها:

```sh
npx playwright install chromium
npm test
npm run test:moonex
```

پس از تغییر هندسهٔ VELO، با `npm run render:models` رندرهای ثابت را دوباره بسازید و سپس `npm run build` را اجرا کنید.

اگر مرورگر جداگانه دارید، مسیر آن را با `BROWSER_EXECUTABLE` و آرگومان‌های لازم را به‌صورت آرایهٔ JSON در `BROWSER_ARGS` بدهید. آزمون‌ها سرور محلی خودشان را باز و در پایان می‌بندند؛ اجرا به سرویس خارجی نیاز ندارد.

## راوا — اجرای جدید

طرح Heepzy مرجع ترتیب بخش‌هاست؛ برند، نشان، پالت، متن فارسی و تصاویر اصلی راوا مستقل طراحی شده‌اند. طبق درخواست کاربر، عکس‌های کفش موجود حفظ و همهٔ خروجی‌های تولیدشده به گالری محصولات مرتبط اضافه شدند. تصاویر اصلی اختصاصی و منشأ همهٔ دارایی‌ها در `public/art/heepzy/sources.json` ثبت شده‌اند. نام قدیمی heepzy در فایل‌های داخلی، namespace فنی است.

طراحی در `design-system/rava/MASTER.md`، آزمون سراسری در `output/heepzy/test-report.json`، آزمون اصلاحات B در `output/heepzy/b-fixes-test-report.json` و گزارش موشن در `output/heepzy/motion/report.json` قرار دارند. سوابق نظارت مستقل B در `output/heepzy/b-*-review-*.json` نگه‌داری می‌شوند. اطلاعات دریافت‌کننده فقط در فرم است؛ رسید نمونه شامل اطلاعات هویتی نیست.

```sh
npm run test:rava
npm run test:rava:review
npm run test:rava:motion
npm run capture:rava -- --portfolio
```

آزمون موشن برای ضبط به FFmpeg نصب Playwright نیاز دارد: `npx playwright install ffmpeg`. پس از بازسازی تصاویر نمونه‌کار، `output/heepzy/convert-portfolio.py` را اجرا کنید و دوباره خروجی را بسازید. تصاویر ثبت‌شدهٔ فعلی از اجرای واقعی مرورگر هستند.
