# هویت بصری سایت اصلی

نشان «دو قاب پیوسته» برای همین پروژه با هندسهٔ برداری طراحی شده است. قاب‌های باز و متصل، پیوند طراحی رابط و اجرای سایت را نشان می‌دهند. نام فعلی «استودیو طراحی» حفظ شده است.

- منبع اصلی نشان: `src/assets/brand/studio-mark.svg`؛ هدر و فوتر مستقیماً همین فایل را نمایش می‌دهند.
- ترکیب نوشتاری: یکان‌بخ، وزن SemiBold، در کنار نشان. لوگو از رنگ متن صفحه پیروی می‌کند و در هر دو تم روشن و تیره قابل استفاده است.
- فایل‌های قابل استفاده: `public/portfolio/brand/studio-mark.svg`، `favicon.svg` و `apple-touch-icon.png`.
- نقش‌های خطی پس‌زمینه از همان هندسه با ضخامت کمتر ساخته می‌شوند؛ فایل‌های مرجع قبلی دیگر در این دو موقعیت نمایش داده نمی‌شوند.
- قاب پرتره با CSS و نشان مشترک ساخته می‌شود؛ عکس موجود در خانه و درباره یکسان است و تزئینات تصویری قالب استفاده نمی‌شوند.
- تصویر اشتراک‌گذاری: `public/portfolio/social-studio.png`، اندازهٔ ۱۲۰۰ × ۶۳۰، با نشان و پیام سایت اصلی.

برای بازسازی خروجی‌های هویت، `npm run brand:build` را اجرا کنید. این فرمان به مرورگر Playwright نیاز دارد؛ برای استفاده از مرورگر نصب‌شده می‌توان `BROWSER_EXECUTABLE` را تنظیم کرد. پس از تغییر دارایی‌ها، سایت را دوباره بسازید.

نشان را کشیده، قرینه یا چرخانده نکنید. نسخهٔ تک‌رنگ روی زمینهٔ متضاد استفاده شود. در کاربرد مستقل، پیرامون نشان حداقل ۸ واحد از شبکهٔ ۶۴ واحدی فضای خالی بگذارید. در اندازهٔ زیر ۳۲ پیکسل از نشان تنها استفاده کنید.

آیکن گیت‌هاب به پروفایل تأییدشدهٔ صاحب پروژه لینک می‌دهد و بخشی از نشان اختصاصی استودیو نیست. نشانی حساب‌های اجتماعی دیگر هنگام مشخص‌شدن قابل اضافه‌کردن است.
